🚀 HOW TO USE:

   METHOD 1 - DRAG & DROP (EASIEST):
   ──────────────────────────────────
   1. Find your folder with CSV files
   2. Double-click CSV Merger.bat
   3. Type or paste the folder path
   4. Choose your option (separate or merge)
   5. Done! Merged CSV appears automatically


   METHOD 2 - COMMAND LINE:
   ─────────────────────────
   1. Open CMD in CSV-Merger folder
   2. Type: CSV Merger.bat
   3. Drag folder into window or paste path
   4. Choose merge option
   5. Done!

💡 OPTIONS EXPLAINED:

   SEPARATE:  Keep each CSV file separate (just copies them)
              Input: 10 CSVs → Output: 10 CSVs

   MERGE:     All CSVs combined into ONE master CSV [RECOMMENDED]
              Input: 10 CSVs → Output: 1 mega CSV with all data

   → Put all 50 CSVs in one folder

❓ TROUBLESHOOTING:

   "Python not found"
   → Install Python from: https://www.python.org/downloads/
   → Check "Add Python to PATH" during installation

   "No CSV files found"
   → Make sure your folder actually contains .csv files
   → Check file extensions (must be .csv)

   "Path not found"
   → Right-click folder and select "Copy as path"
   → Paste the path when prompted
